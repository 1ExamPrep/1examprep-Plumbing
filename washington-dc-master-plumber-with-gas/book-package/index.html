About this Master Plumber with Gas package

Prepare for the Washington DC Master Plumber with Gas examination with a focused book package built around the two approved references identified for the current District of Columbia exam. This package includes the 2012 International Plumbing Code and the 2012 International Fuel Gas Code, giving candidates the plumbing and fuel-gas code resources needed for exam-focused preparation.

The Washington DC Master Plumber with Gas examination is administered through PSI for the District of Columbia Board of Industrial Trades. The current examination is identified as 304 Washington DC Master Plumber with Gas and tests candidates across plumbing fixtures and terminology, plumbing fundamentals, traps and cleanouts, special requirements, drainage, venting, water distribution, plan analysis, and fuel-gas systems.

The 2012 International Plumbing Code supports preparation for plumbing-system design and installation, including fixtures, drainage systems, vents, traps, cleanouts, water distribution, piping materials, and sizing requirements. The 2012 International Fuel Gas Code covers fuel-gas piping, sizing, installation, combustion air, appliances, venting, and other requirements associated with gas systems.

This combined credential requires preparation across both plumbing and gasfitting subjects. Candidates should be comfortable moving between the two code books, identifying which reference applies to a question, locating tables efficiently, performing calculations, and interpreting plumbing and gas-system plans under timed testing conditions.

The Washington DC Master Plumber with Gas examination is an open-book test. Both books in this package are approved references for the current examination, making familiarity with their organization an important part of preparation.

Exam Details

The current Washington DC Master Plumber with Gas examination contains 100 multiple-choice questions. Candidates receive a 4-hour time limit to complete the examination.

The current PSI examination content outline is:

  • Plumbing Fixtures and Terminology – 7%
  • Plumbing Fundamentals – 13%
  • Traps, Cleanouts, and Interceptors – 7%
  • Special Requirements – 6%
  • Drainage Requirements – 8%
  • Vent Requirements – 9%
  • Water Distribution – 7%
  • Plan and Analysis – 23%
  • Gas – 20%

Plan and Analysis is the largest individual content category at 23%, while Gas represents 20% of the examination. Plumbing Fundamentals account for another 13%, and Vent Requirements represent 9%.

The exam structure means candidates should prepare for both detailed code questions and practical system-analysis problems. A Master Plumber with Gas candidate may need to evaluate plumbing plans, calculate drainage or water-system requirements, size gas piping, identify appliance requirements, determine venting provisions, or select the proper code section for a particular installation.

The four-hour testing period provides an average of approximately 2.4 minutes per question. Some questions may be answered quickly, while calculations and plan-analysis problems can require substantially more time. Efficient reference-book navigation is therefore an important part of preparation.

Open Book Test

The Washington DC Master Plumber with Gas examination is an open book test.

PSI currently lists both the 2012 International Plumbing Code and the 2012 International Fuel Gas Code as approved references for the examination.

The 2012 International Plumbing Code should be used for questions involving plumbing fixtures, sanitary drainage, vents, traps, cleanouts, water distribution, plumbing materials, piping arrangements, and other plumbing-system requirements.

The 2012 International Fuel Gas Code should be used for questions involving fuel-gas piping, pipe sizing, appliances, combustion air, venting, installation requirements, equipment connections, and related gas-system provisions.

Because two code books are available during the examination, candidates should practice identifying which book applies before beginning a detailed search. A sanitary drainage question should send the candidate directly to the Plumbing Code, while a gas-pipe sizing or combustion-air question should direct attention to the Fuel Gas Code.

PSI permits only the references identified for the applicable examination. Approved reference books must comply with current examination-center rules. PSI permits bound references containing notes written in ink or highlighting in code sections and permits permanently attached tabs. Candidates may not write or mark in their reference books during the examination.

Building familiarity with both references before exam day can help reduce unnecessary searching and preserve more time for calculations, plan analysis, and multi-step problems.

Licensing Steps

The District of Columbia Board of Industrial Trades regulates plumbing and gasfitting licenses in Washington DC. Candidates pursuing the Master Plumber with Gas credential through the examination pathway must satisfy the District's applicable experience and application requirements.

  1. Select the Master Plumber with Gas credential. Washington DC offers plumbing, gasfitting, and combined plumbing/gasfitting licensing categories. This package is designed around the combined Master Plumber with Gas examination.
  2. Complete the required qualifying experience. The current Master examination pathway requires 8 years, or 16,000 hours, of qualifying work experience.
  3. Gather employment documentation. Applicants using the examination pathway must provide tax records and an employment verification letter documenting qualifying experience.
  4. Obtain proper experience verification. Employment verification should be signed by the supervising master and describe the length and nature of the applicant's qualifying work.
  5. Prepare the general application materials. Current Board requirements include a passport-style photograph, government-issued identification, and payment information for applicable application and licensing charges.
  6. Submit the Washington DC licensing application. Complete the applicable Master Plumber with Gas application through the District's occupational and professional licensing process.
  7. Receive examination eligibility. Candidates must satisfy the applicable licensing requirements before completing the PSI examination process.
  8. Prepare with both approved references. Study the 2012 International Plumbing Code and 2012 International Fuel Gas Code according to the published content outline.
  9. Take the Master Plumber with Gas examination. The current examination contains 100 multiple-choice questions and provides four hours.
  10. Complete the remaining licensing process. Follow the Board of Industrial Trades requirements after the examination and provide any remaining documentation required for license issuance.

The combined Master Plumber with Gas credential should not be confused with the standard Master Plumber examination. The standard Master Plumber exam focuses only on plumbing content, while the Master Plumber with Gas exam adds a substantial fuel-gas component and requires the International Fuel Gas Code as an additional approved reference.

State Requirements

Washington DC is a federal district rather than a state, but plumbing and gasfitting licenses are regulated locally through the District of Columbia Board of Industrial Trades.

Current District application instructions identify a requirement of 8 years, or 16,000 hours, of qualifying work experience for applicants using the Master examination pathway.

Applicants using this route must provide tax records and an employment verification letter. The employment verification letter should be signed by the master supervising the qualifying work and should describe the applicant's length of employment and practical experience.

The Board's current application information also identifies a Certificate of Completion and employment verification among the documentation that may apply to plumbing and gasfitting applicants depending on the pathway being used.

Washington DC offers separate plumbing, gasfitting, and combined plumbing/gasfitting credentials. Candidates should choose the license and examination that correspond to the type of work they intend to perform.

A Master Plumber with Gas credential combines plumbing and gasfitting responsibilities under the applicable District licensing structure. The individual trade license is separate from a Plumbing and Gasfitting Contractor license.

Businesses performing plumbing or gasfitting contracting work must meet separate District requirements. Current contractor licensing information requires applicable business registration or a certificate of good standing, a designated DC-licensed master tradesperson, and the required plumbing and gasfitting contractor bond.

Washington DC plumbing and gasfitting licenses currently expire on March 31 of even-numbered years. Renewal requirements are separate from the initial examination and licensing process.

Test Information and Study Materials

Plumbing Fixtures and Terminology account for 7% of the examination. Candidates should review plumbing definitions, fixture classifications, fixture installation requirements, clearances, connections, and other fixture-related code provisions.

Terminology matters because the meaning of a defined term can determine how a code provision applies. Become familiar with definitions in both the Plumbing Code and Fuel Gas Code so questions can be interpreted accurately.

Plumbing Fundamentals represent 13%. Review basic plumbing-system principles, materials, installation requirements, calculations, general regulations, and the interaction among water supply, drainage, venting, fixtures, and traps.

Traps, Cleanouts, and Interceptors account for 7%. Study trap seals, prohibited arrangements, cleanout placement, accessibility, interceptors, separators, and requirements affecting specialized waste systems.

Special Requirements represent 6%. Candidates should include specialized plumbing provisions in their preparation rather than concentrating only on drainage and water distribution.

Drainage Requirements account for 8%. Review drainage fixture units, horizontal and vertical drainage piping, building drains, building sewers, slopes, changes in direction, connections, sizing tables, and sanitary drainage materials.

Practice determining fixture-unit loads and selecting the appropriate pipe size from the correct table. Candidates should also understand how different sections of a drainage system relate to one another.

Vent Requirements represent 9%. Study individual vents, common vents, wet venting, circuit venting, vent sizing, vent terminals, vent connections, and the relationship between drainage piping and the vent system.

Venting questions can depend heavily on fixture arrangement and pipe configuration. Practice interpreting diagrams and plans in addition to reading code text.

Water Distribution represents 7%. Review water-service piping, distribution systems, fixture supplies, valves, pressure, backflow protection, water heaters, pipe sizing, and potable-water requirements.

Plan and Analysis is the largest section of the exam at 23%. Candidates should become comfortable interpreting plumbing and gas-system drawings, identifying components, tracing piping arrangements, evaluating system design, and applying code requirements to plans.

Plan-analysis questions may combine several subjects. A single problem could involve plumbing fixtures, drainage sizing, venting, water distribution, gas piping, appliance locations, or several of these areas together.

Test Information and Study Materials (continued)

A productive study method is to break a plan into systems. Analyze the sanitary drainage system first, then vents, water distribution, and fuel-gas piping. This can make complex plans easier to evaluate and reduce the chance of overlooking a system component.

Gas represents 20% of the examination, making it the second-largest content category. Candidates should devote substantial preparation time to the 2012 International Fuel Gas Code.

Gas preparation should include fuel-gas piping materials, pipe sizing, system pressure, installation requirements, appliance connections, shutoff valves, testing, combustion air, and venting.

Gas-pipe sizing calculations deserve repeated practice. Candidates should become familiar with the appropriate sizing tables and know how system length, connected load, gas demand, and pressure conditions affect pipe sizing.

Combustion-air requirements are another important area. Fuel-burning appliances require adequate combustion, ventilation, and dilution air, and the code provides methods for determining the required openings and air supply.

Appliance venting can also involve detailed code requirements. Review vent categories, vent connectors, chimney and vent requirements, termination locations, sizing, clearances, and appliance-specific provisions.

Candidates should practice distinguishing between plumbing venting and fuel-gas appliance venting. Both are tested on the examination, but they are governed by different requirements and appear in different code books.

The examination provides four hours for 100 questions. Candidates should practice timed question sets using both books so selecting the correct reference becomes automatic.

When a practice question is answered incorrectly, identify the cause. The error may involve selecting the wrong book, using the wrong sizing table, misunderstanding a plan, missing an exception, applying an incorrect fixture-unit value, or overlooking a gas-system requirement.

Repeated use of both references helps candidates learn not just the code content but also where information is located. That familiarity can be particularly valuable when working through the 23% Plan and Analysis section and the 20% Gas section.
