## Open Book Test

The Washington DC Master Plumber with Gas examination is an **open book test**.

PSI currently lists both the **2012 International Plumbing Code** and the **2012 International Fuel Gas Code** as approved references for the examination.

The 2012 International Plumbing Code should be used for questions involving plumbing fixtures, sanitary drainage, vents, traps, cleanouts, water distribution, plumbing materials, piping arrangements, and other plumbing-system requirements.

The 2012 International Fuel Gas Code should be used for questions involving fuel-gas piping, pipe sizing, appliances, combustion air, venting, installation requirements, equipment connections, and related gas-system provisions.

Because two code books are available during the examination, candidates should practice identifying which book applies before beginning a detailed search. A sanitary drainage question should send the candidate directly to the Plumbing Code, while a gas-pipe sizing or combustion-air question should direct attention to the Fuel Gas Code.

PSI permits only the references identified for the applicable examination. Approved reference books must comply with current examination-center rules. PSI permits bound references containing notes written in ink or highlighting in code sections and permits permanently attached tabs. Candidates may not write or mark in their reference books during the examination.

Building familiarity with both references before exam day can help reduce unnecessary searching and preserve more time for calculations, plan analysis, and multi-step problems.

## Test Information and Study Materials

**Plumbing Fixtures and Terminology** account for 7% of the examination. Candidates should review plumbing definitions, fixture classifications, fixture installation requirements, clearances, connections, and other fixture-related code provisions.

Terminology matters because the meaning of a defined term can determine how a code provision applies. Become familiar with definitions in both the Plumbing Code and Fuel Gas Code so questions can be interpreted accurately.

**Plumbing Fundamentals** represent 13%. Review basic plumbing-system principles, materials, installation requirements, calculations, general regulations, and the interaction among water supply, drainage, venting, fixtures, and traps.

**Traps, Cleanouts, and Interceptors** account for 7%. Study trap seals, prohibited arrangements, cleanout placement, accessibility, interceptors, separators, and requirements affecting specialized waste systems.

**Special Requirements** represent 6%. Candidates should include specialized plumbing provisions in their preparation rather than concentrating only on drainage and water distribution.

**Drainage Requirements** account for 8%. Review drainage fixture units, horizontal and vertical drainage piping, building drains, building sewers, slopes, changes in direction, connections, sizing tables, and sanitary drainage materials.

Practice determining fixture-unit loads and selecting the appropriate pipe size from the correct table. Candidates should also understand how different sections of a drainage system relate to one another.

**Vent Requirements** represent 9%. Study individual vents, common vents, wet venting, circuit venting, vent sizing, vent terminals, vent connections, and the relationship between drainage piping and the vent system.

Venting questions can depend heavily on fixture arrangement and pipe configuration. Practice interpreting diagrams and plans in addition to reading code text.

**Water Distribution** represents 7%. Review water-service piping, distribution systems, fixture supplies, valves, pressure, backflow protection, water heaters, pipe sizing, and potable-water requirements.

**Plan and Analysis** is the largest section of the exam at **23%**. Candidates should become comfortable interpreting plumbing and gas-system drawings, identifying components, tracing piping arrangements, evaluating system design, and applying code requirements to plans.

Plan-analysis questions may combine several subjects. A single problem could involve plumbing fixtures, drainage sizing, venting, water distribution, gas piping, appliance locations, or several of these areas together.

## Test Information and Study Materials (continued)

A productive study method is to break a plan into systems. Analyze the sanitary drainage system first, then vents, water distribution, and fuel-gas piping. This can make complex plans easier to evaluate and reduce the chance of overlooking a system component.

**Gas** represents **20%** of the examination, making it the second-largest content category. Candidates should devote substantial preparation time to the 2012 International Fuel Gas Code.

Gas preparation should include fuel-gas piping materials, pipe sizing, system pressure, installation requirements, appliance connections, shutoff valves, testing, combustion air, and venting.

Gas-pipe sizing calculations deserve repeated practice. Candidates should become familiar with the appropriate sizing tables and know how system length, connected load, gas demand, and pressure conditions affect pipe sizing.

Combustion-air requirements are another important area. Fuel-burning appliances require adequate combustion, ventilation, and dilution air, and the code provides methods for determining the required openings and air supply.

Appliance venting can also involve detailed code requirements. Review vent categories, vent connectors, chimney and vent requirements, termination locations, sizing, clearances, and appliance-specific provisions.

Candidates should practice distinguishing between plumbing venting and fuel-gas appliance venting. Both are tested on the examination, but they are governed by different requirements and appear in different code books.

The examination provides **four hours for 100 questions**. Candidates should practice timed question sets using both books so selecting the correct reference becomes automatic.

When a practice question is answered incorrectly, identify the cause. The error may involve selecting the wrong book, using the wrong sizing table, misunderstanding a plan, missing an exception, applying an incorrect fixture-unit value, or overlooking a gas-system requirement.

Repeated use of both references helps candidates learn not just the code content but also where information is located. That familiarity can be particularly valuable when working through the 23% Plan and Analysis section and the 20% Gas section.
