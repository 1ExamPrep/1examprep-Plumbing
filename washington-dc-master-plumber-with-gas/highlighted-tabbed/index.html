Exam Details

The official examination is identified as the 304 Washington DC Master Plumber with Gas exam. It is an open book examination using both the 2012 International Plumbing Code and 2012 International Fuel Gas Code.

  • Exam: 304 Washington DC Master Plumber with Gas
  • Number of Questions: 100 multiple-choice questions
  • Time Allowed: 4 hours
  • Exam Type: Open book
  • Approved Plumbing Reference: 2012 International Plumbing Code

  • Plumbing Fixtures and Terminology: 7%

This distribution makes balanced preparation important. Candidates should be comfortable with ordinary plumbing code requirements while also giving significant attention to fuel-gas systems and plan-analysis problems.

Washington DC plumbing and gasfitting licenses are regulated through the District of Columbia Board of Industrial Trades. Candidates pursuing a Master Plumber with Gas credential must complete the applicable licensing and examination process.

  1. Review the Master Plumber with Gas classification. Become familiar with the scope of plumbing and gasfitting work associated with the credential.
  2. Prepare required application documentation. Gather the supporting employment, experience, and other documentation required for the applicable licensing pathway.
  3. Submit the licensing application. Complete the District's occupational and professional licensing process for the appropriate plumbing and gasfitting classification.
  4. Complete examination eligibility requirements. Applicants must satisfy applicable qualification requirements before completing the examination process.
  5. Schedule the examination. Washington DC industrial trades examinations are administered through PSI.
  6. Prepare with both approved references. Study the 2012 International Plumbing Code and 2012 International Fuel Gas Code while practicing code navigation and plan-analysis problems.
  7. Take the Master Plumber with Gas examination. Complete the 100-question open book exam within the 4-hour testing period.

The examination is only one component of the licensing process. Candidates should complete all required licensing documentation and qualification steps associated with the Master Plumber with Gas credential.

Test Information and Study Materials

Plumbing Fixtures and Terminology: Review plumbing fixture requirements, fixture connections, installation rules, and commonly used code terminology. Definitions are particularly important because code questions may depend on the precise meaning assigned to a term.

Plumbing Fundamentals: This area represents 13% of the examination. Review general plumbing principles, materials, installation requirements, protection of piping, code organization, and the foundational rules that apply throughout plumbing systems.

Traps, Cleanouts, and Interceptors: Study trap requirements, trap seals, cleanout placement, access, interceptors, separators, and related code provisions. Understand both the purpose of these components and the requirements governing their installation.

Special Requirements: Review systems and installations subject to requirements beyond ordinary drainage, venting, fixture, and water-distribution provisions. Recognizing specialized conditions can help direct candidates to the correct code section.

Drainage Requirements: Study sanitary drainage, fixture units, pipe sizing, slope, horizontal and vertical drainage piping, fittings, cleanouts, and related installation requirements. Practice using the applicable code tables instead of relying only on memorized pipe sizes.

Vent Requirements: Review vent sizing, vent connections, terminals, individual vents, common vents, wet venting, circuit venting, and other permitted arrangements. Candidates should understand why venting is necessary and how different vent methods are applied.

Water Distribution: Study water-supply and distribution piping, sizing, pressure considerations, valves, materials, backflow-related requirements, and connections. Water-distribution questions can require both code lookup and calculations.

Plan and Analysis: At 23%, this is the largest content area. Candidates should practice interpreting plans, system diagrams, isometric information, fixture arrangements, piping layouts, and code-related calculations. Plan-analysis questions often require several pieces of information to be combined before the correct answer can be selected.

Gas: Fuel-gas material represents 20% of the examination. Candidates should give substantial preparation time to the 2012 International Fuel Gas Code. Review gas-piping installations, sizing methods, appliance connections, combustion and ventilation air, chimneys, vents, and applicable installation requirements.

Gas-piping sizing is an especially useful area for table-navigation practice. Candidates should understand how to identify the applicable system conditions, select the correct sizing table, and use the information provided in the problem to determine an appropriate answer.

Test Information and Study Materials (continued)

Candidates should also understand the distinction between plumbing vent systems and fuel-gas venting. The same word can appear in both trades, but the applicable requirements and code locations differ significantly.

A practical study method is to create separate plumbing and gas review sessions, then combine the subjects during timed practice. This helps candidates develop strong knowledge in each code while also practicing the process of choosing the correct reference quickly.

Timed practice can reveal where navigation needs improvement. Track whether missed questions result from technical misunderstanding, choosing the wrong code, difficulty locating a section, or mistakes using a table. Then return to those areas for additional review.
