## Exam Details

For Georgia candidates, the Journeyman Plumber examination is delivered by computer at PSI test centers. The PSI candidate information bulletin describes the Georgia Journeyman exam as follows:

- **Total time:** 5 hours to complete the Journeyman examination.
- **Two-part format:** 2.5 hours for Part 1, then a break, followed by 2.5 hours for Part 2.
- **Question set:** 100 scored test questions plus 20 additional pretest questions (120 total questions presented).
- **Passing standard:** Scores are reported as a final scaled score; a final scaled score of **70** is required to pass.

That structure matters for your study plan. With 120 total questions presented and a fixed time limit, even small improvements in navigation speed can make a meaningful difference. ## Open Book Test

The package is designed for an **open book** testing environment where code lookups are part of the exam strategy. In Georgia, the journeyman reference materials may be used during the examination, while the bulletin notes that reference materials may not be used for the other plumbing exams.

The most effective open-book strategy is built around three skills:

- **Recognition:** identify what the question is really asking (definitions, sizing, materials, installation requirements, prohibited practices, or exceptions).
- **Location:** quickly determine where that topic lives in the code (chapter, section, table, or the index).
- **Confirmation:** verify the requirement in the exact code language, including any exceptions, footnotes, or related provisions.

The IPC is dense by design. Using it well is a learned skill. Tabs support the “location” step by helping you jump to the right chapter area faster, but the real advantage comes from consistent practice with the code until navigation becomes second nature.

## Test Information and Study Materials

Your study is most effective when you combine “know it” learning with “find it” practice. Journeyman plumbing exams are built around real-world plumbing knowledge and code-based decision-making, which means you’ll typically face questions that test your ability to:

- **Interpret code requirements correctly:** understand what is required, what is permitted, and what is prohibited.
- **Navigate drainage and venting rules:** trap and vent concepts, drainage system fundamentals, and code-driven installation requirements.
- **Work through water supply topics:** distribution concepts, fixture supply expectations, and code-driven provisions that impact installation.
- **Apply fixture and installation standards:** practical compliance choices that match the intent of the code.
- **Use definitions and exceptions effectively:** many questions hinge on a definition, a key term, or an exception that changes how a rule applies.

To build speed for an open-book environment, practice with a simple routine:

- **Daily navigation drills (10–20 minutes):** choose a topic and locate 10 related code sections using the index and table of contents, then summarize the rule in one sentence.
- **Timed practice sets (2–3 times per week):** simulate real pressure by setting a timer and forcing yourself to make clean, confident code lookups.
- **Weak-area rotation:** focus on the chapters where you lose time—then repeat them until your search process speeds up.
- **Question-to-code mapping:** after each practice set, write down which IPC chapter/section answered each question. This builds your mental “map” of the book.

The included **Quick Reference Tabs for the 2021 IPC** support this routine by improving physical navigation while you practice. That matters most when you’re under time pressure and need to move directly to the correct chapter area without flipping through dozens of pages.
