## About this Plumbing Code Books and References package

The 2023 Florida Building Code – Plumbing, 8th Edition, published under the authority of the Florida Building Commission (FBC) and adopted by the Florida Department of Business and Professional Regulation (DBPR), serves as the official reference for all plumbing design, installation, and inspection standards statewide. This edition aligns with the International Plumbing Code (IPC) framework and provides updated requirements for water supply systems, sanitary drainage, stormwater management, and fuel gas piping. Used extensively in Florida plumbing contractor license exams administered through PSI and CILB, the book is an essential reference within Pass Your Plumbing Exam’s Florida Plumbing License curriculum. It ensures compliance with Florida Statutes Chapter 553 and supports exam preparation for residential, commercial, and public works plumbing certification. This code volume is also a mandatory text for trade knowledge testing under the Florida Construction Industry Licensing Board (CILB) plumbing division.
