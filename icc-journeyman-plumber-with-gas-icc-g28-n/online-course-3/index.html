Open Book Test

The ICC Journeyman Plumber with Gas G28-N exam is an open book test. Candidates may use the approved references during the exam, but they must know how to use those books efficiently. Open book exams reward preparation, organization, and familiarity with the reference material.

For this exam, candidates should become comfortable using both the International Plumbing Code, 2018 and the International Fuel Gas Code, 2018. You should know how to use the table of contents, index, chapter organization, definitions, tables, footnotes, figures, notes, exceptions, and cross-references. The faster you can identify the correct topic and section, the more time you preserve for complex questions.

A strong open book strategy begins with identifying the subject of the question. If the question involves fixtures, drainage, vents, traps, water distribution, storm drainage, or plumbing plan requirements, the International Plumbing Code is usually the primary reference. If the question involves gas piping, gas appliances, pipe sizing, shutoff valves, regulators, combustion air, vents, chimneys, or fuel gas system installation, the International Fuel Gas Code is usually the primary reference.

Open book does not mean the answer will be obvious. Many questions require careful reading because one measurement, exception, material, system condition, or installation location can change the correct answer. Candidates should practice reading the full question, identifying key terms, choosing the correct reference, and then reading the full code section before selecting an answer.

Test Information and Study Materials

The G28-N exam requires a practical understanding of plumbing systems and fuel gas systems. Candidates should study the International Plumbing Code with attention to the organization of plumbing requirements. General regulations and definitions establish the foundation for code compliance, while later chapters address fixtures, water supply, drainage, vents, traps, interceptors, separators, and storm drainage.

For plumbing fixtures, candidates should review fixture requirements, fixture connections, clearances, installation provisions, and related system requirements. Fixture questions may depend on the type of fixture, the occupancy or use, the connection method, or the system serving the fixture.

For water supply and distribution, candidates should study pipe sizing concepts, water distribution layout, fixture supply requirements, valves, backflow protection, pressure considerations, materials, and system installation. Tables and sizing provisions are important because many water distribution questions require more than a simple lookup.

For sanitary drainage, candidates should review drainage fixture units, pipe sizing, slope, cleanouts, horizontal drainage, vertical stacks, branch connections, offsets, and system layout. Drainage questions often require careful attention to measurements, fixture units, pipe arrangement, and code tables.

For venting, candidates should study vent types, vent sizing, vent connections, distance limitations, vent terminals, wet venting concepts, and special venting arrangements. Venting is a major plumbing exam area because small layout differences can change the requirement that applies.

For traps, interceptors, and separators, candidates should review trap seal requirements, prohibited trap arrangements, cleanout access, grease interceptors, oil separators, indirect waste, and special fixture conditions. These topics often require both code definitions and installation rules.

For storm drainage, candidates should review roof drainage, storm system sizing concepts, secondary drainage, conductors, leaders, and related storm drainage provisions. Although storm drainage is a smaller subject area on the exam, it can still involve specific code requirements and tables.

For gas piping, candidates should study the International Fuel Gas Code carefully. Important areas include gas piping materials, pipe sizing, developed length, appliance input, fittings, valves, regulators, sediment traps, pressure testing, leak detection, protection of piping, appliance connections, combustion air, chimneys, vents, vent connectors, and termination requirements.

Gas questions may require careful table use. Candidates should practice identifying the correct gas type, pressure, developed length, load, branch arrangement, and sizing method. Because gas sizing questions can take more time, practice is important before exam day.

Good preparation includes repeated practice with the approved references. Use the table of contents to understand each book’s structure. Use the index to find terms quickly. Review definitions often. Practice using tables carefully and reading all notes and exceptions. Build the habit of checking the full requirement before selecting an answer.

Timed practice is also important. Since the exam includes 70 questions in 3 hours, candidates should practice moving steadily through questions. Some questions may be answered quickly, while others may require code lookup, table interpretation, or careful comparison between plumbing and gas provisions. Practicing under timed conditions helps candidates learn when to keep moving and when to return to a difficult question later.
