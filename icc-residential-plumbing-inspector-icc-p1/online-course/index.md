## Open Book Test

The ICC Residential Plumbing Inspector P1 exam is an open book test. Candidates may use the approved reference during the exam, but they must know how to use that reference efficiently. Open book testing rewards candidates who are familiar with the book, organized in their study habits, and comfortable locating code requirements under timed conditions.

For this exam, candidates should become comfortable using the International Residential Code, 2021. You should know how to use the table of contents, index, chapter organization, definitions, tables, figures, notes, footnotes, and exceptions. Many residential plumbing inspection questions require more than finding a section number. Candidates must read the full requirement and apply it correctly to the condition described in the question.

A strong open book strategy begins with identifying the subject of the question. If the question involves fixtures, locate the fixture provisions. If it involves water heaters, move to the water heater requirements. If it involves water supply or distribution, focus on supply piping, valves, backflow, sizing, and installation rules. If it involves sanitary drainage or venting, identify whether the question is asking about materials, slope, fixture units, cleanouts, traps, vent size, vent location, or installation method.

Open book does not mean the answer will be obvious. Residential plumbing inspection questions may turn on a specific fixture type, pipe size, fitting, joint, material, slope, developed length, venting method, connection point, water heater safety requirement, cleanout location, or code exception. Candidates should read the full question, identify the key condition, locate the correct section, and review the complete requirement before choosing an answer.

Because the P1 exam includes 60 questions in 2 hours, pacing is important. Some questions may be answered quickly, while others may require more time with the code book. Candidates should avoid spending too much time on one difficult question during the first pass. Mark difficult questions and return to them after answering the questions that can be solved more quickly.
