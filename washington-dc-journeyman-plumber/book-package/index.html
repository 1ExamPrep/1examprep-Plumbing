About this Journeyman Plumber package

Prepare for the Washington DC Journeyman Plumber examination with a focused book package built around the official reference identified for the current District of Columbia exam. The Washington DC Journeyman Plumber examination is administered through PSI for the District of Columbia Board of Industrial Trades. The current examination is based on the 2012 International Plumbing Code and covers plumbing fixtures and terminology, plumbing fundamentals, traps and cleanouts, special requirements, drainage, venting, water distribution, and plan reading.

The 2012 International Plumbing Code provides the code foundation for this examination. Candidates should become comfortable navigating requirements involving fixtures, sanitary drainage, vents, traps, cleanouts, interceptors, water supply and distribution, piping materials, sizing tables, and general plumbing-system installation requirements.

The Washington DC Journeyman Plumber examination is an open-book test. That makes code-navigation practice especially important. Candidates should learn where major subjects are located in the 2012 International Plumbing Code and practice moving quickly between chapters, definitions, tables, and related provisions rather than trying to locate every subject for the first time on exam day.

A strong study plan should combine code reading, calculation practice, plan interpretation, and repeated reference navigation. The Journeyman Plumber exam places particular emphasis on Plan Reading, Drainage Requirements, Vent Requirements, Plumbing Fundamentals, and Water Distribution, so candidates should organize preparation around those major areas while still reviewing the smaller categories.

Exam Details

The current examination is identified by PSI as 302 Washington DC Journeyman Plumber.

The examination contains 70 multiple-choice questions and provides candidates with a 3-hour time limit.

The current examination content outline is:

  • Plumbing Fixtures and Terminology – 6%
  • Plumbing Fundamentals – 14%
  • Traps, Cleanouts, and Interceptors – 6%
  • Special Requirements – 4%
  • Drainage Requirements – 16%
  • Vent Requirements – 16%
  • Water Distribution – 11%
  • Plan Reading – 27%

Plan Reading is the largest individual examination category at 27%. Drainage Requirements and Vent Requirements each represent 16%, while Plumbing Fundamentals account for another 14%. Together, those four categories represent the majority of the published exam outline.

Candidates should be prepared for questions that require both direct code lookup and application of plumbing knowledge. This can include identifying proper pipe sizing, interpreting plumbing layouts, calculating drainage loads, evaluating venting arrangements, determining water-distribution requirements, and identifying code-compliant fixture installations.

The three-hour testing period provides an average of approximately 2.6 minutes per question. Some questions can be answered quickly, while plan-reading questions or problems requiring multiple code tables may take longer. Efficient use of the 2012 International Plumbing Code is therefore an important part of preparation.

Open Book Test

The Washington DC Journeyman Plumber examination is an open book test.

PSI currently identifies the 2012 International Plumbing Code as the approved reference for the Washington DC Journeyman Plumber examination.

Candidates should study directly from the 2012 edition because the current PSI examination reference list specifically identifies that edition for this test. Using the same code edition during preparation helps candidates become familiar with the chapter organization, tables, terminology, and provisions they will use during the examination.

Open-book testing does not eliminate the need to know the material. Candidates should practice recognizing the subject of a question and immediately identifying the most likely chapter or table. A drainage question should direct attention toward the sanitary drainage provisions, while a venting problem should send the candidate toward the venting chapter and related sizing requirements.

Plan-reading questions may require several steps. A candidate may need to identify fixtures on a plan, calculate drainage fixture units, determine pipe size, evaluate venting, or trace a water-distribution system. Familiarity with the IPC makes these multi-step questions easier to manage within the available time.

Reference materials are subject to examination-center rules and inspection. Candidates should prepare the 2012 International Plumbing Code for efficient use before test day and follow all current PSI requirements governing approved reference materials.

Licensing Steps

The District of Columbia Board of Industrial Trades regulates plumbers and gasfitters in Washington DC. Candidates pursuing Journeyman Plumber licensure through the examination pathway must satisfy the applicable experience and documentation requirements.

  1. Select the Journeyman Plumber license category. Washington DC offers plumbing, gasfitting, and combined plumbing and gasfitting credentials. Candidates seeking the standard Journeyman Plumber credential should prepare for examination 302 rather than the Journeyman Plumber with Gas examination.
  2. Complete the required qualifying plumbing experience. The standard examination pathway requires the applicable documented work experience before the candidate sits for the exam.
  3. Gather employment documentation. Applicants using the examination pathway must provide tax records and an employment verification letter documenting qualifying work.
  4. Have qualifying experience verified. The employment verification letter should be signed by the master supervising the work and should describe the length and nature of the plumbing experience.
  5. Prepare the general application materials. Current Board application materials include a passport-style photograph, government-issued identification, and payment information for applicable licensing charges.
  6. Submit the Washington DC licensing application. Complete the applicable Journeyman Plumber application through the District's occupational and professional licensing system.
  7. Proceed through the examination process. Washington DC trade examinations are administered through PSI.
  8. Prepare with the approved reference. Study the 2012 International Plumbing Code according to the current examination outline.
  9. Take the Journeyman Plumber examination. The current exam contains 70 multiple-choice questions and allows three hours.
  10. Complete the remaining licensing requirements. Follow the Board of Industrial Trades instructions after satisfying the examination and documentation requirements.

Washington DC also recognizes an exam-waiver pathway for qualifying applicants who provide proof of completion of a nationally certified apprenticeship program. Candidates using that pathway must provide the required completion documentation.

State Requirements

Washington DC is a federal district rather than a state, but plumbing licenses are regulated locally through the District of Columbia Board of Industrial Trades.

For the standard Journeyman Plumber examination pathway, current District application instructions require 4 years, or 8,000 hours, of qualifying work experience.

Candidates using the examination pathway must provide tax records and an employment verification letter. The employment verification letter should document the length of employment and the type of plumbing work performed and should be signed by the supervising master.

The District also recognizes a waiver pathway for applicants who have completed a nationally certified apprenticeship program. Documentation may include a certificate of completion, formal designation certificate, or official transcripts, depending on the program.

Washington DC offers separate plumbing, gasfitting, and combined plumbing and gasfitting licenses. The Journeyman Plumber exam is different from the Journeyman Plumber with Gas examination. The standard Journeyman Plumber test uses only the 2012 International Plumbing Code, while the combined examination also uses the 2012 International Fuel Gas Code and includes a separate gas-content category.

Current Washington DC plumbing and gasfitting licenses expire on March 31 of even-numbered years. Renewal is handled separately from the initial examination and licensing process.

The individual Journeyman Plumber credential should also be distinguished from a Plumbing Contractor license. A plumbing contractor business must meet separate District business, designated-master, registration, and bonding requirements.

Candidates who plan to move from journeyman-level work toward business ownership or master-level licensing should understand that each credential has its own qualification and application requirements.

Test Information and Study Materials

Plumbing Fixtures and Terminology account for 6% of the examination. Candidates should understand common plumbing definitions, fixture classifications, installation requirements, fixture connections, clearances, and the terminology used throughout the International Plumbing Code.

Definitions can affect the interpretation of many other code provisions. Candidates should become familiar with the terminology used by the IPC so they can understand exactly what a question is asking.

Plumbing Fundamentals represent 14%. Review plumbing-system principles, materials, installation practices, code organization, general requirements, system operation, and practical plumbing calculations.

Journeyman candidates should understand how fixtures, drainage, vents, water distribution, traps, cleanouts, and other components work together as part of a complete plumbing system.

Traps, Cleanouts, and Interceptors account for 6%. Study trap requirements, trap seals, prohibited arrangements, cleanout locations, accessibility, interceptors, separators, and the situations in which specialized devices are required.

Questions may require candidates to determine whether a trap arrangement is acceptable, where a cleanout must be installed, or when an interceptor or separator is required.

Special Requirements represent 4%. Although this is a smaller portion of the examination, candidates should include these provisions in their preparation because specialized plumbing situations can test knowledge outside the major drainage and venting chapters.

Drainage Requirements account for 16%. Candidates should review drainage fixture units, pipe sizing, horizontal and vertical drainage piping, building drains, building sewers, slopes, changes in direction, connections, materials, and sanitary drainage tables.

Drainage calculations deserve regular practice. Candidates should be comfortable determining the fixture-unit load on a section of piping and then using the appropriate IPC table to select the required drainage pipe size.

Vent Requirements also represent 16%. Review individual vents, common vents, wet venting, circuit venting, vent sizing, vent connections, vent terminals, and the relationship between vent systems and trapped fixtures.

Venting questions can be especially sensitive to fixture arrangement and piping configuration. Candidates should practice reading diagrams and plans so they can determine which type of venting method is being used.

Test Information and Study Materials (continued)

Water Distribution accounts for 11%. Study water-service piping, water-distribution systems, fixture supply requirements, pipe sizing, valves, pressure considerations, backflow protection, water heaters, and potable-water system requirements.

Water-distribution questions may require candidates to identify pipe sizes or evaluate whether an installation meets code requirements. Practice moving between tables and related code sections instead of treating each provision separately.

Plan Reading represents 27%, making it the largest section of the current Journeyman Plumber examination. Candidates should be comfortable interpreting plumbing drawings, tracing piping systems, identifying fixtures and fittings, and using plans to answer code-based questions.

Plan-reading questions can combine several plumbing subjects at once. A single drawing may require the candidate to identify a drainage route, determine fixture-unit totals, evaluate venting, locate cleanouts, or determine water-distribution requirements.

A useful preparation technique is to study plans one system at a time. Begin with the sanitary drainage layout, then examine the vent system, water distribution, fixtures, and special devices. Breaking a plan into separate systems can make complex drawings easier to analyze.

The examination allows three hours for 70 questions, so time management matters. Candidates should practice working through question sets under timed conditions and learn when to move on from a difficult problem and return later.

Repeated use of the 2012 International Plumbing Code can improve both speed and confidence. Learn where important chapters begin, which tables appear frequently, and how the IPC directs the reader from one provision to another.

When a practice question is answered incorrectly, determine why. The problem may involve selecting the wrong table, misreading a plan, using the wrong fixture-unit value, confusing drainage and vent requirements, overlooking a special provision, or misunderstanding how a plumbing system is arranged.

Over time, straightforward questions should require less reference searching. Candidates can then reserve more examination time for plan-reading questions, calculations, and detailed code applications.
