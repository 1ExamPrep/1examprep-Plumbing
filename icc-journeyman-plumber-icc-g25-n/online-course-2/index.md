## Open Book Test

The ICC Journeyman Plumber G25-N exam is an open book test. Candidates are allowed to use the approved reference during the exam, but they still need to prepare carefully. Open book exams reward candidates who know how to use the book efficiently and understand where information is located.

For this exam, candidates should become familiar with the International Plumbing Code, 2018 before exam day. You should know how to use the table of contents, index, chapter organization, definitions, tables, footnotes, exceptions, and illustrations. A large part of open book preparation is learning how to find the answer quickly once you understand what the question is asking.

Open book plumbing exams often require careful reading. A question may include a fixture type, pipe size, drainage condition, venting arrangement, developed length, water heater issue, backflow condition, or plan detail. One word or measurement can change the answer. Candidates should practice reading each question completely before searching the code book.

A strong open book strategy begins with identifying the topic. If the question involves fixtures, move toward the fixture provisions. If it involves water distribution, locate the water supply chapter and related tables. If it involves drainage or venting, identify whether the question is asking about sanitary drainage, vent size, vent location, cleanouts, fixture units, or traps. If it involves a drawing, read the plan carefully before selecting the code section that applies.

Because the exam is timed, candidates should also practice pacing. Do not spend too long on one question during the first pass. Mark difficult questions and return to them after answering the questions you can solve more quickly. This habit can help protect your time and reduce exam-day pressure.

## Test Information and Study Materials

The G25-N exam requires a practical understanding of plumbing systems and the ability to apply the International Plumbing Code, 2018. Candidates should study the code with attention to how plumbing requirements are organized. General regulations establish the foundation for code compliance, while later chapters address fixtures, water heaters, water distribution, drainage, venting, traps, interceptors, separators, and storm drainage.

For general regulations, candidates should review code administration concepts, definitions, materials, installation requirements, inspections, and basic compliance language. These topics help build the foundation for understanding how the rest of the code applies.

For plumbing fixtures, candidates should study fixture requirements, installation provisions, clearances, connections, fixture types, and related accessibility or service requirements when applicable. Fixture questions may require careful reading because the correct answer can depend on the type of fixture, its location, or the system it connects to.

For water heaters, candidates should review installation requirements, safety provisions, temperature and pressure relief requirements, drainage provisions, and related system connections. Water heater questions may include details that affect safety, discharge, location, or installation method.

For water supply and distribution, candidates should study pipe sizing concepts, fixture supply requirements, backflow protection, materials, valves, pressure considerations, and distribution system layout. Tables and sizing rules can be especially important in this area.

For sanitary drainage, candidates should review drainage fixture units, pipe sizing, slope, cleanouts, connections, offsets, horizontal and vertical drainage concepts, and system layout. Drainage questions often require attention to measurements, fixture units, pipe arrangement, and specific code tables.

For vents, candidates should study vent types, vent sizing, vent connections, vent terminals, wet venting concepts, distance limitations, and venting arrangements. Venting is a major part of plumbing exam preparation because small layout differences can change the correct requirement.

For traps, interceptors, and separators, candidates should review trap seal requirements, prohibited trap arrangements, grease interceptors, oil separators, indirect waste, and special fixture or system conditions. These topics often involve both code definitions and installation rules.
