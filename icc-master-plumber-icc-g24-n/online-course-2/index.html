Open Book Test

The ICC Master Plumber G24-N exam is an open book test. Candidates may use the approved reference during the exam, but they must know how to use the book efficiently. Open book testing rewards candidates who are organized, familiar with the code book, and comfortable locating information under timed conditions.

For this exam, candidates should become comfortable using the International Plumbing Code, 2018. You should know how to use the table of contents, index, chapter organization, definitions, tables, figures, footnotes, notes, and exceptions. Many questions require more than finding a section number. Candidates must read the full requirement and apply it correctly to the situation described in the question.

A strong open book strategy begins with identifying the subject. If the question involves plumbing fixtures, water heaters, water distribution, sanitary drainage, venting, traps, cleanouts, interceptors, separators, storm drainage, or plan reading, locate the chapter or section that applies before searching in detail. Choosing the right part of the code book first can save valuable exam time.

Open book does not mean the answer will be obvious. Many questions turn on a specific condition, fixture type, pipe size, developed length, drainage fixture unit value, venting arrangement, cleanout requirement, storm drainage condition, or exception. Candidates should practice reading the question fully, locating the relevant section, and confirming the answer before moving on.

Because the G24-N exam includes 100 questions, pacing is important. Candidates should avoid spending too much time on one question during the first pass. Mark difficult questions and return to them after answering the questions that can be solved more quickly. Test Information and Study Materials

The G24-N exam requires a strong understanding of plumbing systems and the ability to apply the International Plumbing Code, 2018. Candidates should study the code with attention to how plumbing requirements are organized. Administration and definitions establish the foundation for code compliance, while later chapters address fixtures, water heaters, water distribution, drainage, vents, traps, interceptors, separators, storm drainage, and other plumbing system requirements.

For administration and general regulations, candidates should review code scope, permits, inspections, approvals, materials, installation requirements, maintenance responsibilities, and general compliance language. Definitions are especially important because plumbing code terms can control how a question should be interpreted. Terms related to fixtures, drainage systems, vents, developed length, cleanouts, backflow, indirect waste, traps, and storm drainage can affect the correct answer.

For plumbing fixtures, candidates should review fixture requirements, fixture connections, clearances, installation provisions, indirect waste conditions, accessibility-related plumbing provisions when applicable, and related system requirements. Fixture questions may depend on the type of fixture, its location, the connected system, or a specific installation condition.

For water heaters, candidates should review installation requirements, access, safety provisions, relief valves, discharge piping, drainage provisions, and related system connections. Water heater questions may involve specific safety details, installation locations, or required components.

For water supply and distribution, candidates should study pipe sizing concepts, fixture supply requirements, backflow protection, valves, pressure considerations, materials, distribution layout, and system installation. Tables and sizing provisions are important because many water distribution questions require careful code application.

For sanitary drainage, candidates should review drainage fixture units, pipe sizing, slope, cleanouts, horizontal drainage, vertical stacks, branch connections, offsets, and system layout. Drainage questions often require attention to measurements, fixture units, pipe arrangement, and code tables.

For venting, candidates should study vent types, vent sizing, vent connections, vent terminals, wet venting, distance limitations, and special venting arrangements. Venting is a major plumbing exam area because small layout differences can change the requirement that applies.

Test Information and Study Materials (continued)

For traps, interceptors, and separators, candidates should review trap seal requirements, prohibited trap arrangements, cleanout access, grease interceptors, oil separators, indirect waste, and special fixture or system conditions. These topics often require both code definitions and installation rules.

For storm drainage, candidates should review roof drainage, storm system sizing, secondary drainage, conductors, leaders, and related provisions. Storm drainage questions may involve tables, rainfall rates, roof areas, or drainage system layout.

Plan reading is also important for master-level plumbing preparation. Candidates should practice reading plumbing layouts, riser diagrams, pipe sizes, fixture locations, vent arrangements, drainage paths, cleanout locations, storm drainage layouts, and notes. Plan-reading questions may require candidates to interpret the drawing first and then apply the correct code requirement.

Good preparation includes repeated practice with the actual reference. Use the table of contents to understand the book’s structure. Use the index to find terms quickly. Review definitions often. Practice using tables carefully and reading all notes, exceptions, and footnotes. Build the habit of checking the full requirement before selecting an answer.

Timed practice is also important. Since the exam includes 100 questions in 4 hours, candidates should practice moving steadily through questions. Some questions may be answered quickly, while others may require code lookup, table interpretation, or plan-reading review. Practicing under timed conditions helps candidates learn when to keep moving and when to return to a difficult question later.
