**2) Learn to confirm instead of reread**
 A common time trap is rereading large sections when one sentence decides the answer. Train a confirm-and-move habit. When you locate the section, scan for language that changes what applies:

- **Conditions** that define when a rule applies
- **Exceptions** that modify or remove a general rule
- **Definitions** that change what the scenario actually means
- **Requirement language** that signals what must be done

Over time, you get faster because you’re no longer “reading for comfort”—you’re confirming what decides the outcome.

**3) Build memory of location with repeated lookups**
 Open-book exams reward familiarity. You build familiarity by repeatedly locating common categories of information. Each successful lookup strengthens your memory of where similar requirements live and how the code organizes related rules. That familiarity reduces stress because you don’t feel lost when a question is worded differently than expected—you have a method for finding what controls the answer.

**4) Practice pacing like it’s part of the skill**
 Even when you have references available, time is still limited. Train pacing intentionally. Use a simple rule during timed practice: confirm what you can efficiently, make the best supported selection, and move forward. If you’re stuck in a long search, it usually means the topic label or first-book decision needs improvement.
